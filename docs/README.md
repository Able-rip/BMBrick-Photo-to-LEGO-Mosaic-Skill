# BMBrick Engineering Documentation

Public technical documentation for the [BMBrick](https://www.bmbrick.com) color quantization pipeline and the [`@bmbrick/agent-mosaic-skill`](https://www.npmjs.com/package/@bmbrick/agent-mosaic-skill) MCP server that exposes it to AI agents.

## Color quantization pipeline

The flagship engineering document. Covers the current pipeline architecture, the architectural decisions that shaped it, verified principles, failed experiments from 25+ versions of iteration, and parameter sensitivity reference. Reading time: ~30 minutes.

- 🇬🇧 **English** — [color-pipeline.md](./color-pipeline.md)
- 🇨🇳 **中文** — [color-pipeline.zh-CN.md](./color-pipeline.zh-CN.md)

**Best for:** image processing engineers, computer vision engineers building image-to-physical-output systems, anyone working on constrained color quantization problems.
